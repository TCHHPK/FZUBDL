# 名词解释

## Q1

### cell calling

10x 单细胞实验中，每个液滴理论上是
├── 一个细胞
├── 带 barcode 的 bead
└── 反应液

测序完成以后，你会得到大量 barcode。

算法必须判断：
AAAC001 → cell
AAAC002 → cell
...
AAAC922 → background
AAAC923 → background

这个过程就是 cell calling

以后会经常看到：

raw_feature_bc_matrix/
filtered_feature_bc_matrix/

可以粗略理解：

raw
↓
cell calling
↓
filtered

也就是：

raw = 很多 barcode，包括空液滴
filtered = Cell Ranger 判断为“细胞”的 barcode

### UMI

(Unique Molecular Identifier)唯一分子标识符 / 唯一分子标签

可以把它理解成：

给每一个原始 RNA/cDNA 分子贴一个随机“身份证号码”。

例如
gene: kdrl
RNA molecule 1 → UMI: ACTGCA
RNA molecule 2 → UMI: GGATTC
RNA molecule 3 → UMI: TCAAGG

因为测序前要 PCR 扩增。

原来只有：

1 个 RNA

PCR 后可能产生：

RNA/cDNA 原始分子
↓ PCR
100 个 copies

如果单纯数 reads：

100 reads

你可能误以为：

有 100 个 kdrl RNA。

实际上只是：

1 个 RNA 被 PCR 复制了 100 次。

有 UMI 后：

read 1 kdrl UMI=ACTGCA
read 2 kdrl UMI=ACTGCA
read 3 kdrl UMI=ACTGCA
...
read 100 kdrl UMI=ACTGCA

算法发现：

gene 相同
cell barcode 相同
UMI 相同

于是认为它们来自同一个原始分子：

100 reads
↓ UMI 去重
1 molecule

offical def：
UMI 用来区分同一细胞内不同的转录本分子，从而判断哪些 reads 来自同一个 transcript molecule

以后看到：

nCount_RNA = 5300

在典型 Seurat/10x 数据里，基本可以理解成：

这个细胞检测到了大约 5300 个 UMI counts，

而不是“5300 条 sequencing reads”。

### molecule

molecule = 推断得到的一个原始 cDNA / RNA 转录本分子。

在 Cell Ranger 的概念中，一个 cDNA molecule 通常由：

Cell Barcode

- UMI
- Gene

共同确定。10x 的 Cell Ranger 源码中也将 cDNA molecule 定义为一个独特的 (BC, UMI, gene) tuple。

ex.
Cell barcode = CELL001

Gene UMI
kdrl AAAA
kdrl BBBB
kdrl CCCC
kdrl CCCC
kdrl CCCC

最终：

kdrl = 3 molecules

也就是表达矩阵里大致：

          Cell001

kdrl 3
gata1a 0
mpx 0

有一个非常重要的关系：

Reads
↓ 根据 UMI 去除 PCR duplicates
Molecules / UMI counts
↓
Gene × Cell expression matrix

刚开始学单细胞时，可以暂时记：

read ≠ molecule
UMI count ≈ detected molecule count

### gata1a

全名：GATA binding protein 1a

编码一个转录因子，与：

hematopoiesis（造血）
primitive erythrocyte differentiation（原始红细胞分化）

密切相关。

所以在斑马鱼单细胞数据中，如果一个 cluster 出现：

gata1a ↑

你首先应该想到：

erythroid lineage（红系细胞）

先简单记：

gata1a → 红细胞

### kdrl

全名：kinase insert domain receptor like

是斑马鱼一个蛋白编码基因，属于 receptor tyrosine kinase / VEGF receptor 相关系统，参与循环系统发育；历史名称中也包括 VEGFR-2、vegfr2 等。

它在斑马鱼研究里非常经典，尤其与：

血管内皮细胞（endothelial cells）

### mpx

全名：myeloid-specific peroxidase

是一种过氧化物酶相关基因。ZFIN 显示它参与炎症反应、细菌反应以及 H₂O₂ 代谢等过程。

在斑马鱼研究中它是非常经典的：neutrophil / granulocyte marker

也就是：

中性粒细胞 / 粒细胞 marker。

### Q1总结

假设你拿到一个斑马鱼 scRNA-seq 数据：

FASTQ
│
↓
Cell Ranger
│
├── Cell barcode
├── UMI
└── gene
│
↓
cell calling
│
↓
去掉 empty droplets
│
↓
UMI deduplication
│
↓
molecule counts
│
↓
Gene × Cell matrix
│
↓
Seurat clustering
│
↓
找 marker genes

然后出现三个 cluster：

Cluster A
gata1a ↑↑↑
→ erythroid / 红系

Cluster B
kdrl ↑↑↑
→ endothelial / 血管内皮

Cluster C
mpx ↑↑↑
→ neutrophil / 中性粒细胞
